# E-commerce-Data-Analysis-SQL-PowerBI

Portfolio project showcasing expertise in data pipeline development using SQL for complex querying and data modeling. The resulting dataset is used to build a dynamic, interactive E-commerce Sales and Operations dashboard in Power BI, with a focus on delivering data-driven insights.

Key Elements :

Project Goal - The primary goal is to perform an in-depth data analysis of the E-commerce dataset using SQL to derive key business insights and then visualize these insights through a dynamic, interactive dashboard built in Power BI. The ultimate objective is to provide actionable intelligence regarding sales performance, customer behavior, and product trends to inform strategic business decisions.

Tools Used - SQL, the core tool used for Data Extraction, Transformation, and Aggregation. This includes querying the database, cleaning data (handling nulls, duplicates), defining new calculated columns, and creating summarized tables (data marts) for visualization.The tool used for Data Modeling, Visualization, and Interactive Reporting. It connects to the SQL output, manages relationships between tables, enables complex measure creation using DAX and generates the final, professional dashboard.

SQL Queries - Queries using GROUP BY and DATE functions to aggregate sales and profit by day, month, and year. This reveals growth patterns, seasonality, and performance over time. Queries using GROUP BY and ORDER BY with LIMIT (or Window Functions) to rank products by revenue, quantity sold, or profit margin. This identifies best and worst performers.
